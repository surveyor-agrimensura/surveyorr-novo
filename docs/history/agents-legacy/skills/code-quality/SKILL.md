# Code Quality

# Qualidade de código
Siga formatter/linter do projeto. Reduza duplicação e complexidade acidental; use nomes claros; mantenha funções coesas; remova morto só com evidência. Separe limpeza grande de correção funcional quando possível para facilitar revisão.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
