# Requirements Contract

# Contrato de requisitos
Produza: objetivo; estado atual; estado desejado; atores; pré-condições; fluxo principal; erros/casos-limite; requisitos não funcionais; não-objetivos; critérios de aceite; hipóteses. Cada critério deve ser testável sem depender de interpretação subjetiva.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
