# Security Review

# Security review
Modele ativos/fronteiras, avalie authn/authz, input/output, sessão, secrets, storage, network, dependencies e logging. Classifique explorabilidade×impacto. Não declare vulnerabilidade sem evidência e não ataque produção.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
