# Incident Response

# Incident response
Preserve evidências; registre timeline, versão, ambiente e sintomas; separe mitigação de correção definitiva; faça análise de causa baseada em fatos; crie ações preventivas, testes e observabilidade. Produção exige rollback e autorização proporcional ao risco.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
