# Secure Coding

# Secure coding
Valide entrada, encode output conforme contexto, aplique autorização no trust boundary, use APIs seguras/parametrizadas, proteja segredos, limite privilégios, trate upload/path, defina timeout e não vaze detalhes internos.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
