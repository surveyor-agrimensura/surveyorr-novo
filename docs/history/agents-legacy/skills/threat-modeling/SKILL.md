# Threat Modeling

# Threat modeling
Identifique ativos, atores, trust boundaries, entradas, dados e integrações. Enumere ameaças relevantes (ex.: STRIDE), controles existentes, lacunas e testes de segurança. Priorize cenários plausíveis e de alto impacto.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
