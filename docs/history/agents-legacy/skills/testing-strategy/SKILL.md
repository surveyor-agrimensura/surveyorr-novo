# Testing Strategy

# Estratégia de testes
Converta critérios em casos; cubra happy path, negative path, boundaries, persistência e integração. Escolha unit/integration/contract/e2e pelo risco. Mantenha testes determinísticos e reteste todo bug corrigido.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
