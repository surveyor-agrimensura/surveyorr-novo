# Release Readiness

# Release readiness
Confirme requisitos, auditoria, segurança proporcional, testes, build, migrações, backup/rollback, docs e changelog. Diferencie ready-to-merge de ready-to-production. Qualquer BLOCKER => NO-GO.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
