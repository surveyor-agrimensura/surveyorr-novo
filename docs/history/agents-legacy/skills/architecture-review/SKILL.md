# Architecture Review

# Revisão de arquitetura
Mapeie componentes e dependências tocados; valide direção das dependências, coesão, acoplamento, contratos, falhas, testabilidade e migração. Gere ADR somente quando decisão estrutural for material.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
