# Code review
Revise requisito→diff→testes. Examine erros, estado, concorrência, recursos, validação, compatibilidade e caminhos negativos. Achado precisa de localização, impacto, severidade e correção recomendada.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
