# Integration Resilience

# Integração resiliente
Confirme docs/versionamento. Defina timeout, retry apenas quando seguro, backoff, idempotência, circuit breaking/fallback, validação de webhook, observabilidade e testes com falhas simuladas.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
