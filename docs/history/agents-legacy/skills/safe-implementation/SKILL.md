# Safe Implementation

# Implementação segura
1. Leia contexto. 2. Reproduza/entenda problema. 3. Faça menor patch completo. 4. Trate erros. 5. Preserve contratos. 6. Adicione/atualize teste. 7. Rode formatter/lint/test/build relevante. 8. Revise diff antes de entregar.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
