# Data Pipeline Safety

# Data pipeline safety
Defina schemas, validação, idempotência, checkpoint/retry, rejeições, lineage e privacidade. Nunca descarte erro silenciosamente. Meça memória/throughput com volume representativo.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
