# Impact analysis
Localize ponto de mudança, callers/callees, dados, eventos, contratos, testes, configs e consumidores. Classifique risco direto/indireto e sugira regressões mínimas obrigatórias.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
