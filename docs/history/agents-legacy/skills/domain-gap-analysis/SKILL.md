# Domain Gap Analysis

# Análise de lacunas
Liste competências necessárias e compare com equipe. Para cada lacuna, escolha uma saída: pesquisa primária, skill, MCP/ferramenta, especialista temporário ou escalonamento humano. Não crie agente redundante.


## Evidência
Nunca registre etapa como concluída sem evidência observável. Declare explicitamente itens não executados ou não verificáveis.
