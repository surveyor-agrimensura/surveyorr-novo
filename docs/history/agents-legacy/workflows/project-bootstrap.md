# /project-bootstrap

1. Coordenador + research analisam estrutura, stack, comandos e documentação sem editar.
2. Analista de Requisitos/Regras de Negócio identificam capacidades e fluxos principais existentes.
3. Arquiteto cria mapa de arquitetura real, não idealizada.
4. Banco, segurança, build e testes mapeiam riscos e comandos.
5. Analista de Lacunas identifica especialistas de domínio.
6. Arquiteto de Documentação grava/atualiza `.agents/team-docs/PROJECT_CONTEXT.md` com fatos verificáveis.
7. Não faça refactor durante bootstrap.
8. Entregue riscos críticos e próximos passos.
