# Matriz de Participação — Surveyor

A equipe multiagente deste repositório atua exclusivamente no Surveyor. O coordenador técnico geral distribui tarefas entre arquitetura, frontend, backend/APIs, segurança, geoespacial, banco de dados, QA, performance, acessibilidade, documentação e release.

É proibido misturar neste repositório arquivos, instaladores ou rotinas de outros produtos desktop.
